### 1. 회원탈퇴 다시 만들기

6/24 의 탈퇴는 로그인만 돼 있으면 확인 없이 바로 됐고, 상태를 휴면으로 적어서 휴면 회원과 구분이 안 됐다. 이메일과 아이디가 그대로 남아 같은 이메일로 다시 가입할 수도 없었다. 이번에 이 세 가지를 고쳤다.

탈퇴 요청에는 이제 비밀번호를 같이 보내야 하고, 틀리면 "아이디나 비밀번호가 맞지 않음"으로 거절한다. 상태에는 "탈퇴"를 새로 만들었고, 휴면은 "1년 동안 접속하지 않은 회원" 용도로만 남겼다. 이메일은 `withdrawn_{회원번호}@deleted`, 로그인 아이디는 `withdrawn_{회원번호}` 로 바꾼다. 이메일과 아이디는 회원끼리 겹치면 안 되는 칸이라, 회원번호를 넣어 겹치지 않게 하면서 원래 값을 비워 준 것이다. 그래서 같은 이메일로 새로 가입할 수 있다. 이름은 "(탈퇴한 사용자)"로 바꾸고 휴대폰·생일·성별은 비운다. 비밀번호도 빈 값으로 바꿔서 다시 로그인할 수 없게 했다. 본인인증 식별값(CI/DI)은 6/24 처럼 지우고, 카카오·네이버·구글 연결 정보는 연결할 때 받은 이메일도 개인정보라서 행째 지운다. 주문 기록은 전자상거래법상 5년 보관 의무가 있어 그대로 둔다. 코드 설명에는 "주문에 남아 있는 받는 사람 이름·주소는 따로 일괄 작업으로 지울 것"이라고 적혀 있는데, 이날 기준으로는 아직 남아 있다.

구조도 조금 바뀌었다. 5/7 부터 회원 서비스는 DB 를 직접 다루지 않는 함수 묶음이었는데, 이번에 처음으로 저장소를 받아 쓰게 됐다. 비밀번호 변경과 탈퇴에서 겹치던 비밀번호 확인도 함수 하나로 합쳤다.

### 4. 화면 배송지를 서버에 연결

배송지 목록 보기, 추가, 수정, 삭제를 6/20 서버 기능에 그대로 맞춰 연결했다. 서버는 주소를 "주소1/주소2"로, 화면은 "주소/상세주소"로 부르고 있어서 서로 바꿔 주는 부분을 두었다. 로그인했을 땐 서버 목록을 쓰고, 로그인하지 않았을 땐 브라우저 저장을 쓴다. 수정은 화면을 먼저 바꾸고 서버에 보내는데, 서버가 실패하면 바꾸기 전 값으로 되돌리고 창에 "저장에 실패했어요"를 띄운다.

기본 배송지를 지웠을 때는 서버가 다른 배송지를 기본으로 올려 주지 않는다(6/20 에 그렇게 정했다). 그래서 화면이 남은 배송지 중 첫 번째를 기본으로 바꾸는 요청을 직접 보낸다. 배송지 화면의 입력 양식은 페이지 안에 펼쳐지던 방식에서 팝업 창("새 배송지"/"배송지 수정")으로 바뀌었고, 별칭과 메모 칸이 생겼고, 저장하는 동안 버튼이 눌리지 않는다.

### 5. 카카오 우편번호 검색

주소를 손으로 치지 않고 카카오 우편번호 검색으로 고르게 했다. 이 검색 도구는 따로 키가 필요 없고, 처음 "주소 검색"을 누를 때만 불러온다. 불러오다 실패하면 다음에 눌렀을 때 다시 시도한다. 휴대폰에서 새 창이 뜨지 않도록 팝업 대신 배송지 창과 주문서 안에 끼워 넣었고, 불러오는 동안 로딩 표시와 "취소" 버튼을 둔다. 주소를 고르면 우편번호와 도로명 주소(없으면 지번 주소)가 자동으로 채워진다. 서버 쪽에 주소 검색 기능을 따로 만들 계획이었는데, API 설계 문서에 "만들지 않고 검색 도구로 대신한다"고 고쳐 적었다. 5/2 문서에 "또는 검색 도구 권장"이라고 적어 둔 쪽을 고른 것이다.

{% hint style="info" %}
**직배송 판정이 믿을 만해졌다**

6/20 부터 직배송 가능 여부는 우편번호 앞 두 자리로 판정한다. 주소를 손으로 치던 때는 우편번호가 틀릴 수 있었는데, 검색 도구가 정확한 5자리 우편번호를 넣어 주니 판정도 믿을 만해졌다.
{% endhint %}

### 6. 회원탈퇴 창과 공용 팝업 창 부품

내 정보 화면의 "회원탈퇴"를 누르면 비밀번호를 묻는 창이 뜨고, 확인하면 서버에 탈퇴를 보낸 뒤 로그아웃한다. 배송지 화면과 내 정보 화면에 비슷한 팝업 창 코드가 따로 있어서, 공용 부품(89줄)으로 뽑았다. 제목, 닫기 버튼, 안에 넣을 내용 자리가 있고, 휴대폰에서는 아래에서 올라오는 시트로, PC(768px 이상)에서는 화면 가운데에 뜬다. 열고 닫을 때 움직임이 있고, 바깥을 눌러도 닫히지 않게 하는 설정을 둬서 입력하던 내용이 날아가지 않게 했다. `CLAUDE.md` 에 입력칸을 두고 적어 둔 "같은 게 또 생기면 공용 부품으로 뺀다"는 규칙을 팝업 창에 적용한 셈이다.
