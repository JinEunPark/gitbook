# 06.28 · 탈퇴 개인정보 익명화, 배송지 연결

회원탈퇴에 비밀번호 확인과 개인정보 익명화를 추가하고 탈퇴 상태를 분리했다. 배송지 별칭·메모를 추가하고 배송지 CRUD와 카카오 우편번호 검색을 프론트에 연결했다. 작업 시각은 09:55, 10:03이다.

| 작업                         | 근거 커밋           |
| -------------------------- | --------------- |
| 탈퇴 개선, 배송지 별칭·메모           | `c6b1a0f` 09:55 |
| 배송지 CRUD, 카카오 주소 검색, 탈퇴 모달 | `838c850` 10:03 |

## 회원탈퇴 개선

탈퇴 요청에 비밀번호를 요구하고 `UserStatus.WITHDRAWN`을 추가했다. 이메일과 로그인 ID는 `withdrawn_{회원번호}` 형식으로 변경하고, 이름·휴대폰·생일·성별·비밀번호·CI/DI를 제거한다. 소셜 계정 연결 정보도 삭제한다. 주문 기록은 보관한다. 비밀번호 확인은 `_assert_password()`로 공통화했고, 회원 서비스는 저장소를 주입받도록 변경했다.

{% hint style="danger" %}
**확인된 제약**: 소셜 가입 계정은 무작위 비밀번호를 사용해 비밀번호를 입력할 수 없어 이 시점에는 탈퇴할 수 없다. 이 문제는 [08.27](../2026-08/2026-08-27.md)에서 `has_password` 분기로 수정했다.
{% endhint %}

## 배송지 별칭·메모와 프론트 연결

`addresses.label`(30자)과 `addresses.memo`(200자)를 추가했다. 생성 시 `Address(user_id=..., **data.model_dump())`로 요청 DTO를 전달하도록 정리했다.

프론트는 `GET/POST/PATCH/DELETE /addresses`를 연결하고 서버의 주소1·주소2와 화면의 주소·상세주소를 변환한다. 수정은 낙관적으로 반영하며 실패 시 `Object.assign(a, prev)`로 이전 값으로 복구한다. 기본 배송지를 삭제하면 남은 첫 배송지를 기본으로 설정하는 요청을 보낸다.

## 카카오 우편번호와 모달

카카오 우편번호 검색은 주소 검색 버튼을 눌렀을 때만 로드한다. 로드 실패 시 다음 요청에서 재시도하며, 팝업 대신 배송지 모달과 주문서에 임베드한다. 선택한 주소의 `zonecode`와 `roadAddress || jibunAddress`를 입력한다. `GET /addresses/lookup` 계획은 API 문서에서 삭제했다.

회원탈퇴는 비밀번호 확인 모달에서 요청하고 성공 시 로그아웃한다. 공용 `AppModal`은 모바일에서 하단 시트, 768px 이상에서 중앙 모달로 동작하며 `preventOverlayClose`를 지원한다.
