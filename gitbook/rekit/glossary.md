# 용어 풀이

{% hint style="info" %}
작업 노트에 자주 나오는 말을 소스를 안 봐도 알 수 있게 풀어 둔 노트. 작업 노트를 읽다가 모르는 단어가 나오면 여기부터 본다.

괄호 안의 "Spring 으로 치면"은 Spring Boot·JPA 기준으로 떠올리기 쉽게 붙인 비유다.
{% endhint %}

### rekit 이 뭔가

문을 닫는 가게(카페·식당·매장)에서 나온 가전을 점검해서 싸게 파는 온라인 쇼핑몰이다. 업소용(영업용) 냉장고나 제빙기 같은 물건이 많고, 한 상품이 보통 재고 1개다. 주소는 `rekit.co.kr`.

처음 이름은 rekle 이었는데 상표 문제로 rekit(리키트)으로 바꿨다. 소개도 처음엔 "철거 현장에서 나온 가전"이라고 했다가, 거부감이 든다는 이유로 5/5 에 "폐업 매장에서 나온 가전"으로 바꿨다. 개발과 운영은 혼자 하고, 코드는 대부분 Claude Code 와 같이 썼다.

#### 저장소 두 개

| 이름                              | 무엇                            | 기술                                  | Spring 으로 치면                   |
| ------------------------------- | ----------------------------- | ----------------------------------- | ------------------------------ |
| 프론트 `rekit_client` (폴더 `rekle`) | 사람이 보는 웹 화면 (구매자 화면 + 관리자 화면) | Vue 3 + TypeScript                  | Thymeleaf 화면 대신 브라우저에서 따로 도는 앱 |
| 백엔드 `rekle_backend`             | 화면이 부르는 API 서버 + DB           | Python FastAPI + PostgreSQL + Redis | Spring Boot API 서버             |

#### 화면 구분

* 구매자 화면: 홈, 상품 목록·상세, 장바구니, 주문(체크아웃), 마이페이지, 고객센터.
* 관리자 화면 (`/admin`): 운영자만 들어가는 화면. 대시보드(매출 그래프), 상품 등록·수정, 주문 처리(송장·취소), 회원, 매출.
* 디자인 시안 (`/_design`): 처음에 디자인 도구에서 받은 화면 그림을 그대로 옮겨 둔 참고용 페이지. 실제 서비스에는 안 쓴다.

### 결제 용어

| 용어                 | 뜻                                                                                            |
| ------------------ | -------------------------------------------------------------------------------------------- |
| PG (결제대행사)         | 카드 결제를 대신 처리해 주는 회사. rekit 은 토스페이먼츠를 쓴다(나이스페이는 검토하다가 8/14 에 철회)                              |
| 결제 위젯 / 결제창        | 토스가 제공하는 카드 입력 화면. 카드 번호는 rekit 서버를 거치지 않고 토스로 바로 간다                                         |
| 승인 (confirm)       | 사용자가 결제창에서 결제를 마친 뒤 rekit 서버가 토스에 이 결제를 확정해 달라고 요청하는 단계. 이게 성공해야 돈이 실제로 빠진다                  |
| 웹훅 (webhook)       | 결제 상태가 바뀌었을 때(완료·취소 등) 토스가 rekit 서버에 먼저 알려 주는 요청. 위조될 수 있어서 rekit 은 웹훅을 받으면 토스에 다시 조회해서 확인한다 |
| paymentKey / 거래 ID | 토스가 결제마다 붙여 주는 번호. 환불하거나 조회할 때 쓴다                                                            |
| 취소 / 환불            | 결제 전 주문을 없애는 것 / 결제된 돈을 돌려주는 것. rekit 의 주문 상태도 `CANCELLED`(취소)와 `REFUNDED`(환불)로 나뉜다          |
| 방치 주문              | 주문서는 만들었는데 결제창을 닫고 나가서 결제대기로 남은 주문. 재고를 붙잡고 있어서 시간이 지나면 정리해야 한다(10/16)                       |
| issuerCode         | 토스가 주는 카드사 코드("41" 같은 숫자). 카드사 이름이 아니라서 헷갈리기 쉽다                                              |
