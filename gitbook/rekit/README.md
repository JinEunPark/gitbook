# rekit 작업일지

{% hint style="success" %}
문을 닫는 가게에서 나온 업소용 가전을 점검해서 싸게 파는 쇼핑몰, **rekit(리키트)** 을 혼자 만들면서 쓴 작업일지다. 2026년 5월 첫 화면부터 11월 운영 모니터링까지, 작업한 날마다 한 편씩 모았다.
{% endhint %}

### 이 일지를 읽는 법

* 날마다 맨 위에 그날 한 일을 한 문단으로 요약해 두었다. 바쁘면 그것만 읽어도 흐름이 잡힌다.
* 작업마다 첫 문단은 무엇이 문제였고, 무엇을 바꿨고, 그래서 뭐가 달라졌는지 순서로 썼다. 파일 이름 같은 세부는 섹션 끝 작은 글씨로 내렸다.
* 낯선 말은 [용어 풀이](glossary.md)에 모아 두었다.
* 대부분은 커밋과 대화 기록을 바탕으로 나중에 다시 쓴 소급 일지다. 기록으로 확인하지 못한 부분은 "추정" 상자로 따로 표시했다.
* 서버 주소, 사업자 정보 같은 값은 가렸다.
