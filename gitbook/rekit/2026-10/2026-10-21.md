### 이날을 한 문단으로

토스페이먼츠 전자결제 계약 안내 메일에 회신을 보낸 날이다. 9/13 에 받았던 것과 같은 질문 목록이 다시 왔는데, 이번 메일에는 "한 달 안에 답하지 않으면 신청이 취소된다"는 문구가 있었다. 회신하기 전에 입점 조건 중 "배송 기간을 상품 페이지에 분명히 적을 것"을 맞추려고, 흩어져 있던 배송 안내를 한 곳에 모아 상품 상세·주문서·이용약관이 같은 문구를 보여 주게 했다. 약관에는 배송 조항을 새로 넣었다. 카드사 심사에 꼭 필요한 사이트 하단 전화번호도 채웠고, 메일 서명에 쓸 로고 이미지까지 만들었다. 이 과정에서 직접 배송비가 화면과 실제 결제에서 서로 다르다는 문제를 발견했는데, 지금까지 고치지 않았다(⑮).

### 1. 카드사별 결제창 시험 (대화 14:24\~14:28)

운영 사이트에서 카드를 하나씩 골라 결제창을 열어 보다가, 몇몇 카드는 고르면 옆에 있는 다른 카드사 결제창이 열려서 이상하다고 생각했다. 백엔드 창에서도 "토스뱅크를 골랐는데 하나카드 결제창이 나온다"고 물었다. 버그가 아니라 정상 동작이었다. 자체 결제창이 없는 카드사는 실제로 결제를 처리하는 카드사(매입사)의 창을 빌려 쓴다. BC 계열 은행 카드는 페이북/ISP 창이, 토스뱅크 카드는 하나카드 창이 뜬다. 토스 응답에도 카드를 발급한 회사 코드와 결제를 처리하는 회사 코드가 따로 온다. rekit 은 결제창을 열 때 카드사를 지정하지 않는다.

프론트 창에서 "결제창을 열었다 닫으면 그때마다 결제대기 주문이 남고 재고가 묶인다"는 경고도 나왔다. 그런데 이건 10/16 에 고친 내용(백엔드 0.0.4)을 모르는 창에서 나온 설명이었다. 그 창은 10/16 에 문제를 분석만 했고 수정은 다른 창에서 했다. 0.0.4 가 운영에 올라가 있다면 다시 결제할 때 자동으로 정리된다.

토스 결제 연동 안내 도구가 대화 창을 연 뒤 30초 안에 붙지 않았다. 직접 실행해 보니 7초 만에 응답했고, 처음 실행할 때 패키지를 내려받느라 늦었던 것이었다. 다시 연결하는 방법을 안내받았다.

### 2. 배송 기간 안내를 한 곳으로 모으기

결제사 계약 메일의 판매 정책 조건 네 줄 중에 "배송 기간이 6주를 넘으면 입점 불가", "구매자가 배송 기간을 알 수 있도록 상품 페이지에 분명히 적을 것"이 있었다. 지금 이 조건을 맞추고 있는지 물어봤더니, 네 가지 모두 충족은 하지만 허술한 데가 있다는 답이 나왔다. 상품 상세와 주문서에 "화물택배 약 2\~4일, 직접 배송 1\~2일"이 적혀 있긴 한데, 언제부터 세는 날짜인지가 없고 "약"이라는 표현이 애매했다. 직접 배송은 "시간 협의"라서 최대 며칠인지 알 수 없었고, 이용약관에는 배송 조항이 아예 없었다. 문구도 두 화면에 따로따로 적혀 있었다. 9/13 대화에서는 "상품 상세에 배송 기간이 안 보인다"고 했는데 이날 확인해 보니 이미 있었다. 언제 생겼는지는 따로 찾아보지 않았다.

그래서 배송 방식 정보를 파일 하나로 모았다.

| 배송 방식 | 범위                            | 기간    | 최대   | 배송비     |
| ----- | ----------------------------- | ----- | ---- | ------- |
| 직접 배송 | 서울/경기, 전문 기사가 운반·설치, 방문 시간 협의 | 1\~2일 | 5영업일 | 40,000원 |
| 화물택배  | 대형 가전, 전국                     | 2\~4일 | 7영업일 | 60,000원 |

화면에는 "결제 완료 후 영업일 기준 N\~M일 이내 도착 (최대 K영업일)"처럼 언제부터 세는지와 최대 기간을 같이 보여 준다. 상품 상세는 이 정보로 배송 줄과 배송 기간 줄을 그리고, 주문서는 배송 방식 선택지 아래에 같은 기간 문구를 붙인다.

이용약관에는 제6조(배송)를 새로 넣었다. 기간은 결제 완료일 다음 영업일부터 세고, 배송 방식별 기간은 화면과 같은 값으로 보여 준다. 늦어지면 이유와 예상 일정을 알리고, 상품을 보낼 수 없게 되면 3영업일 안에 환불한다는 내용이다(전자상거래법 제15조). 원래 제6\~8조였던 조항은 제7\~9조로 밀렸다. 다른 화면에서 "제6조"를 가리키는 곳은 없었고, 약관 안에서 동작 불량 환불을 말하는 "제5조에 따라" 부분은 번호가 바뀌지 않아 그대로 맞다.

최대 기간(5영업일, 7영업일)은 Claude 가 임의로 정한 숫자라서 실제로 지킬 수 있는지 확인이 필요하다. 약관 시행일은 그대로 두었는데, 약관 제3조에 따르면 바꾸기 7일 전에 공지해야 한다.

{% hint style="success" %}
**심사나 법적 안내 문구는 한 곳에서 가져다 쓴다**

상품 상세·주문서·약관이 같은 값을 쓰니까 기간을 바꾸면 세 곳이 같이 바뀐다. 약관과 화면이 서로 다른 숫자를 말하는 일을 막을 수 있다.
{% endhint %}

{% hint style="danger" %}
**직접 배송비 — 화면은 4만 원, 실제 결제는 2만 원 (⑮, 지금도 그대로)**

서버는 직접 배송비 40,000원에서 직접 배송 할인 20,000원을 빼고 주문 금액을 계산한다. 5/1 디자인 시안의 장바구니에 있던 "직배송 할인 −20,000원"을 서버만 만들고 화면은 만들지 않은 결과다. 실제 화면(장바구니·주문서·상품 상세·이날 만든 배송 정보)에는 할인 표시가 없다. 그래서 예를 들어 50만 원짜리 상품을 직접 배송으로 고르면 주문서 버튼에는 "540,000원 결제하기"가 뜨는데, 토스 결제창은 서버가 계산한 520,000원으로 열린다. 사용자는 화면보다 2만 원 적게 결제하고, 결제 완료 화면과 주문 내역에는 서버 금액이 보인다. 게다가 이날부터 약관과 상품 상세에 "직접 배송비 40,000원"이 법적 안내처럼 적히게 됐다. 11/16 에 다시 봐도 서버 할인 20,000원은 그대로고 화면 쪽 주문 관련 화면에는 할인 표시가 없다.
{% endhint %}

### 3. 토스 계약 회신 메일 (대화 15:21\~15:22)

계약 안내 메일 전문을 붙여넣었다. 9/13 과 같은 질문 목록에 이번에는 "문의가 많아 회신까지 1\~2개월 걸린다", 상호명·가맹점 번호·신청한 결제 수단(계좌이체, 복합결제, 신용카드), "회신하지 않은 채 1개월이 지나면 신청 건은 취소된다"가 적혀 있었다. 결제 경로를 설명하는 PPT 는 직접 만들어 두었고, 회신에 들어갈 내용을 대표 이름으로 써 달라고 했다.

{% hint style="info" %}
**추정 — 9/13 메일과의 관계**

9/13 대화에도 같은 질문 목록이 있었다. 이번 메일에는 "1개월 넘게 회신하지 않으면 취소"라는 문구가 있고, 9/13 부터 10/21 까지는 38일이다. 9/13 에는 회신 초안만 만들고 실제로는 보내지 않아서 다시 안내가 왔거나, 9/13 에 본 것이 일부만 옮긴 것이었을 수 있다. 이날 회신이 실제 첫 회신일 가능성이 높다.
{% endhint %}

"직접 매입"은 Claude 가 사이트 문구를 보고 짐작해서 쓴 표현이었다. 실제로는 협력업체 매물을 파는 구조라서 이틀 뒤에 바로잡았다(→ [10.23 일지](2026-10-23.md)).

전화번호가 꼭 사업장 유선 전화여야 하는지, 개인 휴대폰도 되는지 물었다. 메일에 휴대폰 번호도 등록할 수 있다고 적혀 있어서 가능하다는 답을 받았다. 대신 통신판매업 신고 때 쓴 번호와 맞춰야 하고, 번호가 사이트 하단에 공개되니 월 몇천 원짜리 0505 안심번호나 070 인터넷 전화를 만들어 휴대폰으로 돌려받는 방법도 있다고 했다. 일단 개인 번호로 하기로 했다.

### 5. 메일 서명

브랜드 아이콘을 넣은 메일 서명을 만들어 달라고 했다. 네이버 메일이나 Gmail 은 SVG 이미지를 보여 주지 못해서 로고를 PNG 로 바꿔(3배 크기) 사이트에 올렸다. 서명은 왼쪽에 로고(사이트 링크), 브랜드 초록색 세로줄, 이름·상호·전화·이메일·사이트 주소, 아래에 사이트 하단과 같은 소개 문구를 넣은 HTML 이다. 로고는 사이트 주소에서 불러오기 때문에 배포를 해야 보인다. 그래서 로고를 사이트에 올리는 방법으로 정했다. 서명 파일은 처음에 작업용 임시 폴더에만 있어서 위치를 물었고, 다운로드 폴더 아래 `rekit-signature` 폴더(서명 HTML, 미리보기 이미지, 로고)로 옮겨 받았다.
