# 09.13 · 토스 계약 심사 시작, 첫 매물 정리

첫 실제 매물 6개의 등록 데이터와 가격을 정리하고, 토스페이먼츠 실결제 계약 심사에 필요한 사이트 정보를 점검했다. 저녁에는 심사에 필요한 사업자 정보·환불 정책·연락처를 보완하고, 마이페이지의 고정 데이터를 실제 데이터로 교체했다.

| 작업                | 근거 커밋             |
| ----------------- | ----------------- |
| 통신판매업 신고번호와 환불 규정 | `d2db2a8` (0.0.3) |
| 고객센터·개인정보처리방침 연락처 | `719e5e5` (0.1.0) |
| 마이페이지 실제 데이터 연결   | `275ba5c` (0.2.0) |

## 첫 매물 데이터

주방가전 카테고리에 재고 1개, 판매중 상태의 상품 6개를 준비했다.

| 상품                    | 등급 |    최종 가격 |        배송비 |
| --------------------- | -- | -------: | ---------: |
| 라셀 4도어 업소용 냉장고        | B  | 450,000원 | 40,000원 별도 |
| 엔터팩 트레이 포장기 EPQ-350N2 | B  | 300,000원 | 40,000원 별도 |
| 우성 테이블형 냉장고           | A  | 250,000원 | 40,000원 별도 |
| 린나이 가스 튀김기            | C  | 180,000원 | 40,000원 별도 |
| 다이나믹 제빙기              | A  | 300,000원 | 40,000원 별도 |
| 매직세븐 후드형 식기세척기        | B  | 250,000원 | 40,000원 별도 |

사진으로 확인 가능한 상태와 모델 정보를 기준으로 초안을 만들었다. 치수, 무게, 동작 여부는 확인 자료가 없어 입력하지 않았다. 운영 DB 등록 여부는 이 날짜의 기록만으로 확인하지 못했다.

## 토스 계약 심사 준비

심사 회신에 필요한 상품 주소, 환불 정책 주소, 상품 설명, 최고 결제 금액, 심사용 계정, 배송 기간, 결제 경로 자료를 정리했다. 사이트 하단의 사업자 정보와 결제 흐름을 점검했다.

환불 정책은 수령일 포함 7일 이내의 단순 변심, 왕복 배송비 부담, 도착 후 7일 이내 동작 불량의 전액 환불을 구분해 약관 제6조에 반영했다. 통신판매업 신고번호도 하단에 추가했다.

연락 이메일은 실제 수신 가능한 주소로 교체했다. 기존 `rekit.kr` 표기는 `rekit.co.kr`와 달라 잘못된 주소였다.

## 마이페이지 실제 데이터 연결

마이페이지에 남아 있던 고정 주문·찜·배송지 수치를 제거했다. 로그인한 사용자의 주문 상태별 개수, 진행 중 주문, 찜 수, 배송지 수, 본인 인증 상태를 서버 데이터로 표시하도록 변경했다. 주문 상태 링크도 한글 상태명 대신 API가 사용하는 영문 상태 값을 전달하도록 수정했다.

## 확인된 제약과 후속 작업

* 주문 목록 첫 페이지 20건만 조회하므로 주문이 20건을 넘으면 상태별 개수가 실제보다 적을 수 있다.
* 약관의 단순 변심 7일·왕복 배송비 규정은 당시 환불 API에 구현되지 않았다.
* 심사 회신 발송, 심사용 계정·결제 경로 자료·최고 결제 금액 결정, 실제 매물 등록은 이 날짜의 기록으로 확인하지 못했다.
* 하단 유선 전화번호와 상품 상세 배송 기간 표시는 [10.21 일지](../2026-10/2026-10-21.md)에서 보완했다.
