# 문제 해결 사례

실제 서비스를 운영하며 마주친 문제를 **측정 → 원인 분석 → 해결 → 재측정** 순서로 정리합니다. 모든 사례는 고치기 전의 기준선과 고친 뒤의 결과를 같은 조건에서 잰 수치로 남깁니다.

## 사례 목록

| #  | 사례                                                 | 프로젝트  | 핵심 성과                                             |
| -- | -------------------------------------------------- | ----- | ------------------------------------------------- |
| 01 | [상품 이미지 로딩 18.2초 → 1.8초](case-01-image.md)         | rekit | 목록 이미지 전송량 **-92%**, 4G 로딩 **10배** 단축             |
| 02 | [검색봇에 에러 문구만 보여주던 프리렌더 HTML](case-02-prerender.md) | rekit | 검색봇이 보는 상품 링크 **0 → 6**, 에러 문구 **0건**, 재발 시 빌드 중단 |

{% hint style="info" %}
추정치는 본문에 "추정"이라고 따로 표시합니다. 표시가 없는 수치는 모두 직접 측정한 값입니다.
{% endhint %}

## 프로젝트 소개

**rekit** (`rekit.co.kr`): 폐업 매장에서 나온 업소용 가전을 검수해 직거래로 판매하는 플랫폼. 1인 개발로 프론트엔드(Vue 3 · TypeScript), 백엔드(FastAPI · PostgreSQL), 인프라(Docker · Jenkins · nginx · SeaweedFS · Prometheus/Grafana)를 모두 맡고 있습니다.
