## 카드사별 결제창 확인

운영 사이트에서 카드사별 결제창을 열어 확인했다. 일부 카드에서 선택한 카드사와 다른 결제창이 열렸지만, 자체 결제창이 없는 카드사가 실제 결제를 처리하는 카드사의 창을 사용하는 정상 동작이었다. BC 계열 은행 카드는 페이북/ISP, 토스뱅크 카드는 하나카드 결제창이 열릴 수 있다. 토스 응답도 발급 카드사 코드와 매입 카드사 코드를 구분한다. rekit은 결제창을 열 때 카드사를 지정하지 않는다.

토스 결제 연동 안내 도구도 다시 연결했다. 최초 실행에서 패키지를 내려받느라 연결이 늦었고, 직접 실행했을 때는 7초 안에 응답했다.

## 배송 기간 안내 통합

계약 조건의 배송 기간 안내 요구에 맞춰 기존 화면과 약관을 정리했다. 기존에는 상품 상세와 주문서에 “화물택배 약 2~~4일, 직접 배송 1~~2일”이 있었지만, 기준 시점·최대 기간·약관 안내가 빠져 있었다.

배송 정보를 한 파일로 통합했다.

| 배송 방식 | 범위                            | 기간    | 최대   | 배송비     |
| ----- | ----------------------------- | ----- | ---- | ------- |
| 직접 배송 | 서울/경기, 전문 기사가 운반·설치, 방문 시간 협의 | 1\~2일 | 5영업일 | 40,000원 |
| 화물택배  | 대형 가전, 전국                     | 2\~4일 | 7영업일 | 60,000원 |

상품 상세와 주문서에는 “결제 완료 후 영업일 기준 N~~M일 이내 도착 (최대 K영업일)”을 표시하도록 했다. 이용약관에는 제6조(배송)를 추가해 결제 완료일 다음 영업일부터 기간을 계산하고, 지연 시 사유·예상 일정을 알리며 배송 불가 시 3영업일 안에 환불한다는 내용을 반영했다. 기존 제6~~8조는 제7\~9조로 이동했다.

{% hint style="warning" %}
### 확인이 필요한 값

최대 배송 기간 5영업일과 7영업일은 실제 운영 가능 여부를 확인해야 한다. 약관 시행일을 유지하려면 제3조에 따라 변경 7일 전 공지도 필요하다.
{% endhint %}

{% hint style="danger" %}
### 직접 배송비 표시 불일치

서버는 직접 배송비 40,000원에서 20,000원을 할인해 계산하지만, 화면은 40,000원만 표시한다. 예를 들어 500,000원 상품을 직접 배송으로 주문하면 주문서 버튼은 540,000원으로 보이고 토스 결제창은 520,000원으로 열린다. 화면에 할인 항목을 추가하거나 배송비 표시를 서버 계산과 맞춰야 한다. 11월 16일 확인 시점에도 남아 있었다.
{% endhint %}

## 토스 계약 회신

계약 안내 메일의 질문에 맞춰 회신을 작성하고 결제 경로 PPT를 첨부했다. 메일에는 회신이 없으면 1개월 후 신청이 취소될 수 있고, 답변까지 1\~2개월이 걸릴 수 있다고 안내돼 있었다.

| 질문       | 회신 내용                                             |
| -------- | ------------------------------------------------- |
| 상품 주소    | `https://rekit.co.kr/products`와 상세 예시             |
| 환불 정책    | 이용약관 제7조                                          |
| 상품 설명    | 업소용 중고 가전, A/B/C 등급, 실물 상품, 정기결제 없음, 배송 2종, 환불 기준 |
| 최고 결제 금액 | 1,200,000원, 배송비 별도 최대 60,000원                     |
| 테스트 계정   | 이메일 가입 계정. 심사자의 휴대폰 확인 통과 여부는 추가 확인 필요            |
| 최대 배송 기간 | 결제 완료 후 영업일 기준 최대 7일                              |
| 연동 방식    | 앱 없이 직접 만든 홈페이지에 토스 결제 위젯 직접 연동                   |
| 심사 준비    | 판매 상품 6개, 사업자 정보, 결제창 연동, 결제 경로 PPT               |

이 회신에는 당시 사이트 문구를 기준으로 “직접 매입”이라고 적었다. 실제 판매 구조는 10월 23일에 다시 정리했다. → [10.23 일지](2026-10-23.md)
